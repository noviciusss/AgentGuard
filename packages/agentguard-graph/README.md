# agentguard-graph

Optional Mermaid graph visualization plugin for AgentGuard.

## Usage

Render normalized graphs from a Python file or directory:

```console
agentguard graph path/to/agent.py
agentguard graph path/to/agent/ --output agent.mmd
```

The command operates on AgentGuard's normalized IR, so it does not import or
execute the analyzed source. Modules, graphs, nodes, edges, and fan-outs are
sorted before rendering. Node IDs are generated by the renderer and labels are
escaped for Mermaid, including quotes, brackets, HTML characters, and line
breaks.

Malformed Python files are skipped with a warning on stderr. Missing inputs,
invalid configuration, and output-file errors return exit code 2.

The IR uses `Edge.target is None` for both unresolved conditional targets and
edges to a terminal. The renderer uses the graph's terminal metadata to
interpret that value; an IR edge with a `None` target whose source is also
marked terminal is therefore inherently ambiguous and is rendered as a
terminal edge.

# AG004: unbounded-agent-loop

## What it detects

Cycles in LangGraph, CrewAI, or AutoGen agent graphs without a configured
recursion, iteration, or round limit.

## Why it matters

An agent cycle without a bound can run forever, consume tokens, and prevent a
worker from serving other runs.

## Bad example

```python
builder.add_edge("review", "revise")
builder.add_edge("revise", "review")
```

## Good example

```python
graph = builder.compile()
graph.invoke(state, {"recursion_limit": 12})
```

## How to fix

Configure `recursion_limit`, CrewAI `max_iter`, or AutoGen `max_round` and keep
an explicit terminal path.

## How to suppress

Use `# agentguard: ignore[AG004] reason: supervisor enforces the limit` when an
external supervisor provides the bound.

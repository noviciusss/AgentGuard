# AG020: prompt-injection-sink

## What it detects

User input or tool output flowing into a system-prompt input.

## Why it matters

Untrusted instructions can override privileged system behavior and redirect an
agent toward unsafe actions.

## Bad example

```python
system_prompt = user_input
SystemMessage(system_prompt=system_prompt)
```

## Good example

```python
SystemMessage(system_prompt=FIXED_POLICY)
HumanMessage(content=user_input)
```

## How to fix

Keep untrusted content in user-data messages, validate tool output, and use a
fixed privileged policy.

## How to suppress

Use AG020 suppression only after reviewing the trust boundary.

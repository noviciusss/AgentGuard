# AG022: llm-output-to-sink

## What it detects

LLM output flowing to `eval`, `exec`, subprocess execution, raw SQL, or a file
path sink.

## Why it matters

Generated text is untrusted and can execute code, alter data, or access files.

## Bad example

```python
command = client.responses.create(model="pinned", input=prompt)
subprocess.run(command)
```

## Good example

```python
action = parse_allowlisted_action(model_output)
dispatch(action)
```

## How to fix

Use typed schemas and allowlists instead of passing generated strings to raw
sinks.

## How to suppress

Use AG022 suppression only when a reviewed parser proves the value is safe.

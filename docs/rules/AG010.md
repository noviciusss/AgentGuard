# AG010: unpinned-model-alias

## What it detects

Literal LLM model names such as `latest`, `gpt-4`, or `claude-3` without a
dated provider revision.

## Why it matters

Floating aliases can change quality, behavior, availability, and cost without a
source change.

## Bad example

```python
client.responses.create(model="latest", input=prompt)
```

## Good example

```python
client.responses.create(model="gpt-4-2024-08-06", input=prompt)
```

## How to fix

Pin the provider's dated or immutable model identifier and update it
deliberately.

## How to suppress

Use AG010 suppression when a deployment manifest pins the alias externally.

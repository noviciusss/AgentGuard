# AG011: unbounded-state-growth

## What it detects

Message, history, or state collections appended inside a loop without a
visible trimming policy.

## Why it matters

Unbounded state increases memory use and sends increasingly expensive prompts to
the model.

## Bad example

```python
while running:
    state["messages"].append(message)
```

## Good example

```python
state["messages"] = state["messages"][-20:]
```

## How to fix

Window, summarize, or cap the collection before the next cycle.

## How to suppress

Use inline AG011 suppression when a reducer or external state store enforces a
retention limit.

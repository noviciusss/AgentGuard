# AG007: conditional-edge-unmapped-key

## What it detects

Conditional graph edges whose destination cannot be resolved to a path-map
target.

## Why it matters

An unexpected router key can stop execution or raise a runtime graph error.

## Bad example

```python
builder.add_conditional_edges("router", route)
```

## Good example

```python
builder.add_conditional_edges("router", route, {"retry": "worker", "done": END})
```

## How to fix

Map every known return key to a node or terminal and handle unknown values
explicitly.

## How to suppress

Use an inline AG007 suppression when the framework supplies a verified dynamic
map.

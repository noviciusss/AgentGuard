# AG021: dangerous-tool-no-approval

## What it detects

Dangerous shell, deletion, payment, email, file-write, or similar tools with no
visible human approval gate.

## Why it matters

An agent may perform an irreversible action without a person reviewing it.

## Bad example

```python
delete_file_tool(path)
```

## Good example

```python
if human_approved(request):
    delete_file_tool(path)
```

## How to fix

Require explicit approval and narrow the tool's capability scope.

## How to suppress

Use AG021 suppression when approval is enforced by a verified gateway.

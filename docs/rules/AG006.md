# AG006: unreachable-graph-node

## What it detects

Static graph nodes with no path from the declared entry point.

## Why it matters

Unreachable nodes are dead code or a graph wiring error and never perform their
intended work.

## Bad example

```python
builder.add_node("orphan", orphan)
```

## Good example

```python
builder.add_edge("router", "orphan")
```

## How to fix

Connect the node from the entry path or remove it. Check conditional path maps
when the route is dynamic.

## How to suppress

Suppress intentionally unused nodes with an inline AG006 reason.

# AG023: hardcoded-secret

## What it detects

Likely API keys, passwords, tokens, and credential-shaped literals in source.

## Why it matters

Committed credentials can be copied and abused by anyone with repository access.

## Bad example

```python
api_key = "sk-live-value"
```

## Good example

```python
api_key = os.environ["OPENAI_API_KEY"]
```

## How to fix

Use environment configuration, a secret manager, and rotation for any exposed
credential.

## How to suppress

Suppress documented test fixtures with an inline AG023 reason; never suppress
an active credential without rotating it.

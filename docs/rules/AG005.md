# AG005: no-cost-budget

## What it detects

LLM calls inside loops without a literal `max_tokens` budget.

## Why it matters

Repeated or cyclic calls can generate unexpectedly large responses and multiply
token costs.

## Bad example

```python
while needs_more:
    client.responses.create(model="gpt-4", input=prompt)
```

## Good example

```python
for _ in range(3):
    client.responses.create(model="gpt-4-2024-08-06", input=prompt, max_tokens=256)
```

## How to fix

Pass `max_tokens` or the provider's equivalent output-token limit, and bound the
number of calls.

## How to suppress

Use an inline AG005 suppression when a gateway applies the budget.

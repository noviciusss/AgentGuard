# AG002: shared-mutable-fanout

## What it detects

AG002 detects parallel agent branches that write shared mutable state without a
safe merge. It covers LangGraph fan-outs with multiple writers to an unreduced
state key, `Send` fan-outs, module-level mutable objects mutated by concurrent
tasks, and mutable default arguments on parallel task functions.

## Why it matters

Concurrent writes can overwrite one another or raise LangGraph's
`InvalidUpdateError`. The resulting behavior is timing-dependent and difficult
to reproduce.

## Bad example

```python
from langgraph.graph import END, START, StateGraph
from typing_extensions import TypedDict


class State(TypedDict):
    items: list[str]


def left(state: State):
    return {"items": ["left"]}


def right(state: State):
    return {"items": ["right"]}


builder = StateGraph(State)
builder.add_node("left", left)
builder.add_node("right", right)
builder.add_edge(START, "left")
builder.add_edge(START, "right")
builder.add_edge("left", END)
builder.add_edge("right", END)
```

## Good example

```python
from operator import add
from typing import Annotated
from typing_extensions import TypedDict


class State(TypedDict):
    items: Annotated[list[str], add]
```

Alternatively, keep state local to each branch and merge explicit return values
after the parallel work completes. For ordinary Python tasks, protect shared
mutation with the appropriate lock or use per-task state.

## How to fix

For LangGraph, annotate a fan-out key with a reducer that expresses the merge
operation, such as `Annotated[list[str], operator.add]`. For thread or async
tasks, avoid module-level mutable state, pass fresh values to each task, or
hold a lock around every mutation. Replace mutable defaults with `None` and
construct a new object inside the function.

## How to suppress

Suppress a known-safe mutation on its reported line:

```python
pool.submit(worker, item)  # agentguard: ignore[AG002] reason: worker is isolated
```

Use a first-ten-lines file directive only when the entire file has an external
concurrency guarantee:

```python
# agentguard: ignore-file[AG002] reason: scheduler serializes these tasks
```

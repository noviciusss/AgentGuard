# AG003: missing-timeout

## What it detects

AG003 detects known HTTP, LLM, and tool calls where no explicit or configured
timeout can be established. It understands common `requests`, `urllib`,
`httpx`, `aiohttp`, OpenAI, Anthropic, and LangChain call shapes, including
simple client-level timeout assignments.

## Why it matters

A provider connection can hang for a long time and block an agent worker. In a
retry loop, the missing timeout can multiply both latency and cost.

## Bad example

```python
import requests


response = requests.get("https://example.com")
```

## Good example

```python
import requests


response = requests.get("https://example.com", timeout=10)
```

For an SDK client, configure the client once when supported:

```python
from openai import OpenAI


client = OpenAI(timeout=30)
response = client.responses.create(model="gpt-test", input="hello")
```

## How to fix

Pass `timeout=<seconds>` to the call or configure a client-level timeout. For
agent runs, also use an overall deadline so a sequence of individually bounded
operations cannot run indefinitely.

Dynamic `**kwargs` are treated as unknown. Verify that the forwarded mapping
contains a timeout when the rule does not report a definite missing value.

## How to suppress

Suppress a call when an internal gateway or client wrapper enforces the
deadline:

```python
gateway.request(url)  # agentguard: ignore[AG003] reason: gateway adds timeout
```

For a whole file, add the directive within its first ten lines:

```python
# agentguard: ignore-file[AG003] reason: gateway client has a global deadline
```

# AG008: exception-swallowed-in-tool

## What it detects

Tool functions that catch exceptions without raising, logging, or returning an
explicit fallback.

## Why it matters

The agent can continue as if a tool succeeded while silently losing important
work or data.

## Bad example

```python
try:
    delete_tool()
except Exception:
    pass
```

## Good example

```python
except Exception:
    logger.exception("delete failed")
    raise
```

## How to fix

Log the exception, propagate it, or return a typed failure result that the
agent can reason about.

## How to suppress

Suppress an intentional fallback with an inline AG008 reason.
